# Format: montage

B-roll and music lead: travel, a product, a day, a recap. Little or no talking.

| | Default |
| --- | --- |
| **Comes in** | many clips, optionally a voice-over or a few spoken lines, a music track the creator owns or one from the library |
| **Canvas** | 1920×1080 or vertical, the footage's frame rate |
| **Select** | the log describes every clip; the plan picks the strongest few seconds of each |
| **Cut** | on the music: shots change on beats; 1–4 s per shot; a slower passage where the music breathes |
| **Graphics** | a title, place and date labels, an end card; nothing over the best shots |
| **Captions** | only for spoken lines |
| **Music** | the spine of the piece. Chosen at the storyboard gate before anything is cut to it |
| **Loudness** | −14 LUFS |
| **Then** | package · a vertical version |

The paper edit here is a shot list (clip, in, out, why) instead of a struck-through transcript.
