# Format: screencast

A screen recording with a voice: a lesson, a demo, a walkthrough. The screen is the A-roll.

| | Default |
| --- | --- |
| **Comes in** | the screen recording (with or without sound), optionally a face camera and a separate microphone |
| **Canvas** | the recording's size (often 1920×1080 or larger), 30 fps |
| **Cut** | `--natural`. Silent stretches where something happens on screen (typing, a build running) are **kept or sped up, never cut**: the log lists them |
| **Zooms** | a punch-in on the part of the screen being talked about (the log gives where), 130–200%, eased in and out; small text must be readable on a phone |
| **Face camera** | picture-in-picture in a corner that covers nothing important; full frame for the intro and outro |
| **Graphics** | few: chapter cards, a lower third for a term or a shortcut, `over` callouts pointing at the screen |
| **Private things** | anything the log flags (keys, emails, addresses) is blurred (`redact`) |
| **Captions** | subtitle files; code and commands spelled exactly |
| **Music** | none during explanation; optional under the intro and outro |
| **Loudness** | −16 LUFS |
| **Then** | subtitles · package (chapters matter here) · Shorts only when a moment stands alone |
