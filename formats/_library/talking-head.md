# Format: talking head

One person to camera. The voice carries it; graphics support what is said.

| | Default |
| --- | --- |
| **Comes in** | one camera file (or phone), optionally a separate microphone, a screen recording, B-roll, a script |
| **Canvas** | 1920×1080 (or the camera's size), the camera's frame rate |
| **Cut** | `--natural`: mistakes, fillers and retakes out; pauses to the speaker's own rhythm. Content is never removed without a yes |
| **Graphics** | about one beat every 15–25 s. Lower third the first time a name appears; `over` callouts for key phrases and numbers; `pip` for lists and diagrams; `full` rarely and briefly; chapter cards at sections |
| **Punch-ins** | on emphasis and after a cut that would otherwise jump, 110–115% |
| **Captions** | subtitle files; not burned in |
| **Music** | none, or one calm bed from the channel's moods, low and ducked |
| **Effects** | soft, on plate entrances only |
| **Loudness** | −16 LUFS |
| **Then** | subtitles · package · offer Shorts |

Recording tips that make the cut cleaner: `docs/RECORDING-TIPS.md`.
