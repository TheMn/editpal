# Format: short (YouTube Shorts, Instagram Reels)

Made vertical from the start, or cut from a longer video by the `shorts` skill. These specs apply
to both.

| | Default |
| --- | --- |
| **Canvas** | 1080×1920, 30 fps |
| **Length** | 20–60 s is the safe range for both platforms; longer is possible (check the platform's current limit before promising it) |
| **First second** | frame 0 is the thumbnail: a face, the result or one bold line. Never black, never a logo |
| **Hook** | on-screen text for the first 2 s, at most 6 words, not the spoken sentence |
| **Safe area** | nothing in the top 168 px; all words between 168 and 1330 px; below 1330 px only background (the app's caption and buttons sit there); nothing under the right-hand buttons |
| **Captions** | burned in, 2–4 words at a time, the spoken word highlighted, low in the safe band, never over the face. Persian right-to-left |
| **Reframe** | follow the face; a screen recording with a face camera is stacked (screen above, face below), never squeezed |
| **Pace** | a new picture or a punch-in every 2–4 s; the payoff before the end |
| **Music** | optional, under the voice |
| **Loudness** | −14 LUFS |
| **Instagram** | caption: the first 125 characters carry it, up to 5 hashtags; the cover must read when cropped to the centre square |
| **Per language** | one file each: the original voice, and the dubbed voice with captions in that language |
