# Format: faceless (generated)

A script becomes the whole video: voice, graphics, music. Nothing is recorded. Persian or English.

| | Default |
| --- | --- |
| **Comes in** | an idea, notes or a finished text; optionally images, screen captures, a logo |
| **Canvas** | 1920×1080, 30 fps |
| **Script** | the `script` skill: brief → three storylines → script with line ids, in the spoken language |
| **Voice** | the channel's cloned or stock voice (`./pal voice script`), or the creator's narration recorded as audio |
| **Graphics** | everything on screen is built from the script: diagrams, charts, maps, kinetic type, code, the creator's own images. One idea at a time; each visual lands on the word that names it. Text in the channel's on-screen language (Persian is right-to-left) |
| **Build** | up to ~3 min: one project. Longer: one full-frame plate per scene |
| **Captions** | subtitle files; burned in for vertical versions |
| **Music** | one bed that fits the piece's mood, ducked under the voice; effects on visible actions |
| **Loudness** | −16 LUFS |
| **Then** | subtitles · the other language (voice + text re-rendered) · package · Shorts |

Only facts from the script or the brief on screen. A number the script does not give is not shown.
