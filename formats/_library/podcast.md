# Format: podcast / interview

Two or more people, or two or more cameras, recorded together.

| | Default |
| --- | --- |
| **Comes in** | one file per camera, ideally one microphone track per person |
| **Canvas** | 1920×1080, the cameras' frame rate |
| **Sync** | by sound (`./pal sync`); drift between devices is reported |
| **Cut** | `--loose`: conversation keeps its pauses and overlaps. Remove false starts, long dead air, technical interruptions. Content cuts are suggestions |
| **Picture** | the wide shot by default; a person's camera while they speak for more than a few seconds (set by hand as `angle` on kept ranges: automatic switching is on the roadmap) |
| **Graphics** | a lower third for each person the first time they speak; chapter cards; a quote card for the strongest line |
| **Captions** | subtitle files |
| **Music** | intro and outro only |
| **Loudness** | −16 LUFS; each voice levelled before the mix |
| **Then** | subtitles · package (chapters) · Shorts: the best exchanges |

Not yet supported: telling speakers apart on a single shared microphone track.
