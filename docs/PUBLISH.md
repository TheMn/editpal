# Publishing

editpal prepares the files and the text; you upload. (Uploading for you is on the roadmap.)

## YouTube

1. Upload the final video. Paste the title, description (with chapters), tags from `package.md`.
   Set the thumbnail.
2. **Add subtitles.** YouTube Studio → the video → Subtitles → Add language → Upload file →
   "With timing" → the `.srt` for that language. Repeat per language.
3. **Add an audio track** (an extra language in your voice). YouTube Studio → the video →
   Languages → Add language → Audio → upload `<video>.<lang>.m4a`. In the same place paste the
   translated title and description. (Multi-language audio must be enabled for your channel;
   if you do not see it, YouTube has not switched it on for you yet.)
4. **Pinned comment:** post the one from `package.md` and pin it.
5. Tick the disclosures that apply (`package.md` lists them): paid promotion; altered or
   synthetic content. A cloned voice speaking a translation of your own words may count: read
   YouTube's current wording and decide.
6. End screen: the end card leaves room for YouTube's elements; add them in the editor.

## Shorts

Upload each vertical file as a normal video; under 3 minutes and vertical makes it a Short.
One upload per language. Paste its caption from the chat or `episode.md`.

## Instagram Reels

Upload the same vertical file. Caption: the Instagram one from the package (the first 125
characters show before "more"). Choose the cover frame named in the package; check it in the
grid preview (it is cropped to the centre).

## Music claims

Every track used is listed in the video's `credits.md` with its proof page. Public-domain and
CC0 recordings are sometimes claimed by mistake: dispute the claim and paste that page's link.
